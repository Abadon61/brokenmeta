What's still missing

This class isn't complete yet: here's precisely what hasn't been sourced yet, rather than leaving it silent.

  • Only the Combat single-target rotation pieces are covered (Sinister Strike, Backstab, Eviscerate, Slice and Dice). Ambush (stealth opener), Instant Poison (weapon buff named in the real rotation), Gouge, Kick, Sprint, and all Assassination/Subtlety trees are not looked up.
  • French names for Backstab, Eviscerate and Slice and Dice were NOT found from a reliable source this pass (only Sinister Strike's real FR name, "Attaque pernicieuse", is confirmed, via data/wow_talents/rogue.json's own Improved Sinister Strike entry) -- left in English with a note rather than guessed.
  • Eviscerate's Attack-Power scaling coefficient: the tooltip states the ability's damage "increased by Attack Power" but the exact coefficient wasn't visible in the effect breakdown captured this pass (unlike e.g. Mage spells, which show an explicit "SP mod: X").
  • Combat's own Dual Wield Specialization (n105740, Combat tree) wasn't cross-checked against Warrior's for whether Rogue's version has the same real values -- don't assume they match.
  • Real, sourced finding (2026-09-25): Assassination and Subtlety's own level-20 guides describe the SAME sustained single-target core rotation as Combat -- build combo points with Backstab (behind target) or Sinister Strike, spend at 5 combo points on Eviscerate or Slice and Dice. Each spec's real differences are its talents (now catalogued below), a one-time stealth opener (Ambush, Subtlety/Assassination), and poisons (Instant Poison, all three specs -- still unsourced). None of those are modeled by this project's simulator yet, so all three specs currently produce the same simulated number: a real, disclosed limitation, not a mistake. Ghostly Strike (Subtlety's own granted ability, a non-positional Backstab alternative) is real but its own cost/cooldown/damage aren't sourced yet.
